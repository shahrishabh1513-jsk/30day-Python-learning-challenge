## 📖 About

This repository documents my **30 Days of Python Challenge**, a structured journey through core Python fundamentals — from variables, data structures, and loops, all the way to file handling, virtual environments, web scraping, Pandas, building REST APIs, and working with MongoDB.

Each day lives in its own folder with focused, hands-on code, so you can follow along step by step and build strong, practical Python skills one concept at a time.
